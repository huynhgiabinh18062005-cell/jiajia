## 二、作業說明

本次作業使用 Python 製作兩場活動報名整理器，
整理桌遊體驗與電影欣賞的報名名單。

主要功能：

- 移除姓名中的半形空白。
- 將英文姓名統一轉成小寫。
- 去除重複報名的資料。
- 比較兩場活動的參加者。
- 依照英文字母順序排列名單。
- 取得通知名單的前兩位。
- 計算各場活動的人數及應收費用。

## 三、使用的 Python 資料型別

- str：保存原始報名文字。
- tuple：保存兩個固定的活動名稱。
- list：保存整理後的姓名，保留順序與重複資料。
- set：去除重複姓名，進行交集、聯集及差集運算。
- dict：保存活動費用、人數及金額摘要。

## 六、個人回答

### 問題一

測試一中，整理後的桌遊串列有 4 筆資料，
為什麼桌遊費用應以 3 人計算？

回答：

因為 Amy 和 amy 是同一個人，轉成小寫後，
amy 重複出現了兩次，所以實際上只有三位參加者。

list 可以保留原本的順序和重複資料，
而 set 可以保留不同的姓名並去除重複資料，
但不保留原本的順序及重複次數。

因此，桌遊費用應該以三人計算。

3 × 120 = 360 元。

### 問題二

測試三中，兩場活動只有 3 位不同的人，
為什麼是 6 人次、總應收仍是 600 元？

回答：

因為兩場活動去重後的集合完全相同，
所以交集和聯集都只有三個人，
兩個方向的差集都是空集合。

雖然只有三位不同的參加者，
但是每個人都參加了兩場活動，
所以報名人次為 3 + 3 = 6 人次。

兩場活動需要分別收費，因此：

- 桌遊費用：3 × 120 = 360 元。
- 電影費用：3 × 80 = 240 元。
- 總應收：360 + 240 = 600 元。
